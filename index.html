Gestión de Datos

Copias de seguridad, exportación y restauración de tus nóminas

Backup Automático

Desactivado

Si lo activas, cada vez que guardes o corrijas una nómina se descarga un archivo con los datos (sin las fotos ni los PDF) nominas-backup-FECHA.json en tu carpeta de Descargas.

Viene desactivado para no llenarte Descargas de copias. En su lugar, cuando tengas cambios sin copia de seguridad, el Panel te avisa para que descargues el backup completo (datos y nóminas) y lo guardes en Drive.

📲 Modo sin conexión

La app guarda una copia de sí misma para abrirse sin internet. Con conexión descarga siempre la última versión. Si alguna vez ves una versión antigua, fuerza la actualización: tus nóminas y tu API key no se borran.

Exportar datos

Solo los datos de tus nóminas, en un archivo JSON ligero. Es el mismo que el backup automático.

🗂️

Backup completo

Datos y documentos originales en un ZIP ordenado por año. Guárdalo en Drive o donde quieras: sirve para restaurarlo todo en otro dispositivo. En Chrome (Android y ordenador) eliges dónde guardarlo, Drive incluido; en los demás navegadores se descarga.

Restaurar datos

Importa un backup de datos (.json) o un backup completo (.zip, con documentos)

O arrastra aquí un archivo nominas-backup-*.json o .zip para restaurar
