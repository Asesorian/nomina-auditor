Gestión de Datos

Backup automático, exportación manual y restauración de tus nóminas

Backup Automático

Activado

Cada vez que guardes una nómina, se descarga automáticamente un archivo de respaldo nominas-backup-FECHA.json en tu carpeta de Descargas. Si algún día pierdes los datos del navegador, puedes restaurar desde ese archivo.

📲 Modo sin conexión

La app guarda una copia de sí misma para abrirse sin internet. Con conexión descarga siempre la última versión. Si alguna vez ves una versión antigua, fuerza la actualización: tus nóminas y tu API key no se borran.

Exportar datos

Solo los datos de tus nóminas, en un archivo JSON ligero. Es el mismo que el backup automático.

🗂️

Backup completo

Datos y documentos originales en un ZIP ordenado por año. Guárdalo en Drive o donde quieras: sirve para restaurarlo todo en otro dispositivo.

Restaurar datos

Importa un backup de datos (.json) o un backup completo (.zip, con documentos)
